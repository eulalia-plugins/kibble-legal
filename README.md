# Kibble Legal Site

Static Terms of Service and Privacy Policy pages for Kibble.

## Publish with GitHub Pages

1. Create an empty public GitHub repository, for example `kibble-legal`.
2. Run the commands below from this folder:

```bash
git init
git add .
git commit -m "Add Kibble legal pages"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/kibble-legal.git
git push -u origin main
```

3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.

Your URLs will be:

- `https://YOUR_USERNAME.github.io/kibble-legal/terms.html`
- `https://YOUR_USERNAME.github.io/kibble-legal/privacy.html`
